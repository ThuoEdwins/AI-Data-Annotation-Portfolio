# AI Data Annotation and Evaluation Portfolio

Welcome to my portfolio. I am a Computer Science graduate interested in AI data annotation, Large Language Model (LLM) evaluation, and Vision-Language Model (VLM) evaluation.

This repository showcases my independent practice in evaluating AI-generated responses, classifying text, checking data quality, and assessing whether image descriptions accurately represent visual content.

## Skills and Areas of Interest

- **LLM Evaluation:** Assessing factual accuracy, relevance, reasoning, clarity, and instruction-following.
- **VLM Evaluation:** Reviewing image captions, visual question-answering responses, and image-text alignment.
- **Data Annotation:** Text classification, sentiment analysis, labelling, and categorisation.
- **Quality Assurance:** Identifying errors, inconsistencies, unsupported claims, and inaccurate labels.
- **Research and Critical Thinking:** Verifying information and providing clear, evidence-based reasoning.
- **Technical Skills:** HTML, CSS, JavaScript, PHP, MySQL, software testing, debugging, and database management.

## Projects

### 1. AI Response Evaluation
Comparing AI-generated answers to identify factual errors and determine which response better satisfies the user's question.

### 2. Text Classification and Sentiment Analysis
Labelling text according to its sentiment and explaining how context influences the classification.

### 3. Vision-Language Model Evaluation
Assessing whether AI-generated image captions and visual question-answering responses match the available visual evidence.

### 4. Data Quality Review
Reviewing labelled data for inconsistencies, ambiguous classifications, and potential annotation errors.

## My Approach

I focus on accuracy, consistency, attention to detail, and following project-specific guidelines. When evaluating AI outputs, I consider whether claims are supported by evidence, whether instructions have been followed, and whether the response is relevant to the task.

I also recognise that AI-generated content can contain errors, so human review and verification are important parts of the evaluation process.
